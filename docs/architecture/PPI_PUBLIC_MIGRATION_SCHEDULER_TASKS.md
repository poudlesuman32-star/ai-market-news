# PPI Public Migration Scheduler Tasks

This task list is subordinate to the validated Version 1.2 architecture.

1. `T01` — verify public architecture and bootstrap readiness.
2. `T02` — freeze provider licensing dispositions.
3. `T03` — freeze the R1 contract lineage and collector release identity.
4. `T04` — add category-specific public schemas and validators.
5. `T05` — add sharding, bounded retries, and resumable collection.
6. `T06` — separate success and failure artifacts and enforce the exact 50-path package.
7. `T07` — protect provider secrets, pin external Actions, and add attestations.
8. `T08` — freeze the public-to-private handoff and freshness contract.
9. `T09` — build the no-network private artifact consumer.
10. `T10` — run the controlled batch-3 pilot and measure private minutes.
11. `T11` — retire private acquisition and rotate or remove the bootstrap token.

Only one task may be active. A reviewed pull request is required to mark one task complete and activate the next task.
